# DRILL-13 아이템 모드 구현

## 프로젝트 개요

Pico2D 기반 2D 게임에서 아이템 선택 기능을 제공합니다. 아이템 창은 게임 모드 스택에 넣어 플레이를 멈추는 방식이 아니라 플레이 화면 위에 그리는 UI입니다. 따라서 창이 열려 있어도 캐릭터 애니메이션, 이동, 기존 투사체의 이동이 계속됩니다.

## 실행 방법

1. Python과 수업 환경의 Pico2D를 준비합니다.
2. `transitions` 라이브러리를 설치합니다.
3. 저장소 폴더에서 `python main.py`를 실행합니다.

이미지 파일은 프로젝트 폴더에 두고 파일명 상대경로로 불러옵니다.

## 조작법

| 화면 | 키 | 동작 |
| --- | --- | --- |
| 로고 | Esc | 프로그램 종료 |
| 타이틀 | Space | 플레이 시작 |
| 타이틀 | Esc | 프로그램 종료 |
| 플레이 | ← / → | 캐릭터 이동 및 방향 전환 |
| 플레이 | Space | 선택한 공 발사 |
| 플레이 | I | 아이템 선택창 열기 또는 닫기 |
| 아이템 창 | 0 | 발사 안 함 |
| 아이템 창 | 1 | 작은 공(21x21) 선택 |
| 아이템 창 | 2 | 큰 공(41x41) 선택 |
| 플레이 | P | 일시정지 |
| 일시정지 | P | 플레이 재개 |
| 플레이 또는 일시정지 | Esc | 타이틀로 돌아가기 |

아이템 창은 0, 1, 2를 선택해도 유지되며 I를 다시 눌러 닫습니다. 창이 열린 상태에서도 방향키와 Space를 사용할 수 있습니다.

## 구현 요약

- `item_mode.py`가 선택창 표시 상태와 숫자 키 선택을 관리합니다.
- `play_mode.py`가 I 입력을 처리하고 플레이 장면 위에 선택 이미지를 그립니다.
- 아이템 창이 열려 있어도 `game_world.update()`를 매 프레임 호출합니다.
- `Boy`가 발사 선택 값을 보관하고, `Ball`이 작은 공과 큰 공 리소스를 사용합니다.
- 필요한 이미지와 코드 파일을 저장소에 포함했습니다.

## AI 활용 및 제출 설명

AI 도움으로 요구사항 분해, 아이템 오버레이와 발사 유형 연결, 문서를 작성했습니다. 제출 본문에는 다음 설명을 붙일 수 있습니다.

> 아이템 모드는 I 키로 여닫는 비정지형 오버레이입니다. 열린 동안에도 캐릭터와 월드 업데이트가 계속됩니다. 0은 발사 안 함, 1은 21x21 작은 공, 2는 41x41 큰 공이며 Space로 선택한 공을 발사합니다.
